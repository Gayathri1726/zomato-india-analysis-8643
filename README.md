# Zomato India Analysis - 8643 Restaurants
End-to-end Data Analysis project on Zomato's restaurant data across India.
### Project Overview
This project analyzes 8643 restaurants listed on Zomato to understand customer preferences, rating trends, and market insights. The analysis was done using Python and visualized in Power BI.

### Tools Used
- Python (Pandas, Matplotlib, Seaborn) - for Data Cleaning & EDA
- Power BI - for Interactive Dashboard
- Excel / CSV

### Files in this Repo
- `zomato_for_powerbi.csv` - Cleaned dataset with 8643 restaurants
- `analysis.ipynb` - Python notebook with full EDA
- `Zomato Dashboard.pdf` - Dashboard PDF

### Key Insights
- **Online Delivery:** Restaurants with online delivery have higher average ratings (4.1 vs 3.8)
- **Top Cuisines:** North Indian, Chinese & Fast Food are most popular
- **Cost vs Rating:** No direct correlation - high cost doesn't mean high rating
- **Top City:** Bangalore has highest number of listed restaurants

###  Dashboard
Power BI dashboard includes:
- Total Restaurants, Avg Rating, Avg Cost KPI Cards
- City-wise distribution
- Rating vs Cost analysis
- Cuisine popularity

###  How to Use
1. Download `zomato_for_powerbi.csv`
2. Open Power BI file to explore dashboard
3. Check `analysis.ipynb` for detailed code
